# ArrayList Implementation (Java)

A custom implementation of a dynamic array data structure in Java, similar to Java's built-in ArrayList.

## Features
- Dynamic resizing of underlying array
- Add and remove elements
- Sorting functionality
- Duplicate removal
- Merge and intersection operations

## Implementation Details
- Uses generics for type flexibility
- Maintains sorted state tracking
- Implements common list operations

## Technologies
- Java
- Data structures and algorithms
